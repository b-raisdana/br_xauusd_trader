# Research Handoff

1. Read the changed research docs and current Git diff.
2. Separate:
   - confirmed Rules;
   - experiments/hypotheses;
   - Leader Decisions;
   - implementation outcomes.
3. Reject ambiguous silent rule changes: if a Rule materially changed without explicit Leader approval, escalate.
4. Commit the coherent documentation handoff before implementation when practical.
5. Convert outcomes into a small executable TODO set.
6. Define acceptance evidence.
7. Implement autonomously.
8. Update test/experiment/current-state evidence after execution.
