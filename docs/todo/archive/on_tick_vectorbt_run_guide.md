## What the Tests Cover

| Test | Scenario |
|---|---|
| Normal tick processing | All bars processed; probe fires on ticks 1-5; event loop succeeds |
| Probe emit limit | Probe count reaches exactly 5 |
| Event loop disabled | Event loop skipped; probes fire |
| Event loop absent | Failure reported on first call |
| Event loop exception | Exception caught; failure reported; processing continues |
| Invalid ticks | No probe emitted; no exception; event loop still called |
| Full integration | Consistent results; no state corruption |
| Alias behavior | Entry point alias matches primary |
| Delegation | Direct delegation to event loop |
| Delegation failure | Direct delegation returns failure |
