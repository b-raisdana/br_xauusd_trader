# Running on_tick.py vectorbt Backtesting Tests

## Prerequisites

- Active Python environment with vectorbt installed (v0.28.2 per `docs/RUNBOOK.md`)
- `data/random_ohlcv.csv` present (generated by `scripts/generate_random_ohlcv.py`)

## Generate Test Data

```powershell
.\.venv\Scripts\python.exe scripts/generate_random_ohlcv.py
```

This creates `data/random_ohlcv.csv` — 50 M15 bars with edge cases (zero volume, doji, monotonic trend).

If the CSV already exists, re-running is safe (deterministic, seed=42).

## Run Tests

```powershell
.\.venv\Scripts\python.exe -m pytest tests\test_on_tick_vectorbt.py -v
```

Expected output: **10 passed**.

## Run with Other Tests

```powershell
.\.venv\Scripts\python.exe -m pytest tests/ -v
```

This includes `test_dummy.py` (vectorbt/numba smoke test) and `test_on_tick_vectorbt.py` together.

## What the Tests Cover

| Test | Scenario |
|------|----------|
| `test_scenario_1_normal_tick_processing` | All 50 bars processed; probe fires on ticks 1–5; event loop succeeds |
| `test_scenario_2_probe_emit_limit` | `time_basis_probe_count` reaches exactly 5 |
| `test_scenario_3_event_loop_disabled` | `run_current_event_loop=False` skips event loop, probes fire |
| `test_scenario_4_event_loop_absent` | `event_loop=None` returns `handled=False`, `event_loop_failed=True` |
| `test_scenario_5_event_loop_exception` | Exception on tick 25 caught; failure reported; processing continues |
| `test_scenario_6_invalid_ticks` | NaN/zero prices: no probe emitted, no exception, event loop still called |
| `test_scenario_7_vectorbt_integration_loop` | Full vectorbt iteration; consistent results; no state corruption |
| `test_scenario_8_handle_tick_alias` | `handle_tick is on_tick` |
| `test_process_current_event_loop_tick_delegation` | Direct delegation to event loop |
| `test_process_current_event_loop_tick_failure` | Direct delegation returns `False` |

## Debugging

To inspect a single tick result:

```powershell
.\.venv\Scripts\python.exe -c "
import pandas as pd
from application.xauusd_trading_strategy_1.lifecycle import Tick, RuntimeEnvironment
from application.xauusd_trading_strategy_1.on_tick import on_tick
from application.xauusd_trading_strategy_1.settings import StrategySettings
from application.xauusd_trading_strategy_1.global_state_variable import StrategyRuntimeState

df = pd.read_csv('data/random_ohlcv.csv', parse_dates=['Datetime'], index_col='Datetime')
settings = StrategySettings(run_current_event_loop=True, emit_time_basis_probe=True)
runtime = StrategyRuntimeState()
tick = Tick(time=df.index[0], bid=float(df['Close'].iloc[0]), ask=float(df['Close'].iloc[0]))
result = on_tick(tick, settings, runtime, RuntimeEnvironment(), None)
print(result)
print('probe_count:', runtime.time_basis_probe_count)
print('failure_reported:', runtime.event_loop_failure_reported)
"
```
